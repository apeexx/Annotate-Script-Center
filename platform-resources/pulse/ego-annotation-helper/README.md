# Pulse 分段标注助手资料

## 目录职责

- `page-structure/`：已采样标注页的 DOM 结构、时间换算输入和安全挂载点。
- `reference/`：禁用词 Excel 的格式口径与当前参考源。

## 当前能力

- 从当前选中分段的内联 `left / width` 与时间线总宽度换算秒数；仅拖动分段框左右边界或其相邻拖拽柄时，额外按每次指针位移计算“分段长度 Ns · 变化 ±Ns”，因此不等待页面在松手后写回样式。分段框中间和普通进度条不参与预览。右上角已有的起止时间与秒数保持由 Pulse 原页面负责显示。
- 在精确“中文翻译” textarea 下方显示只读文本镜像；禁用词按大小写敏感的字面子串、最长词优先匹配，不改写标注文本。脚本中心可由用户本地导入 `.xlsx` 禁用词表，确认保存后当前浏览器的词表优先于内置词表。
- 不再内置固定规则文案。用户展开“标注规则”时，助手通过任务模板按钮中的文件图标读取当前任务标题精确为“标注步骤”的列表，并以纯文本有序列表展示；任务切换后清空旧内容，等待下一次展开再读取。若为读取而临时打开模板，完成后恢复原先关闭状态。

## 禁用词词表

- 参考源：`reference/禁止使用词汇.xlsx`。
- 运行时回退词表：`extension/sites/pulse/ego-annotation-helper/data/forbidden-terms.json`。
- 本次导入前共有 85 个词项；去除重复“摆弄”后为 84 个词。词表不含网络地址、Cookie、Authorization 或任务内容。
- 用户可在 Pulse 脚本详情拖入普通 `.xlsx`；助手读取首个工作表的首个有内容列，按逗号/顿号拆词、去引号并保序去重。预览后才写入当前扩展的 `chrome.storage.local`，只保存词项、来源文件名和导入时间，不保存 Excel 原文件。
- 自定义词表仅在导入者当前浏览器生效；恢复默认会删除自定义词表并回退内置 84 词，不向 Pulse、后端或其他标注员电脑同步。

## 安全边界

- 不保存、不提交、不审核、不领取、不自动切换任务。
- 不调用 Pulse 平台接口；自定义与内置词表均不可用时仅显示失败状态，不降级请求外部地址。
- 页面无法确认轨道、选中段、总帧数或帧率时仅显示待加载状态，不猜测时间。

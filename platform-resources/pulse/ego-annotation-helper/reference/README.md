# 禁用词参考源

## 来源与导入范围

- `禁止使用词汇.xlsx` 是当前参考格式，原始工作表为 `Sheet1`。
- 自助导入读取第一个工作表的首个有内容列；单元格内容按英文逗号、中文逗号和顿号拆分，去除首尾中英文引号后保持原顺序去重。
- 原始共 85 项，重复项为“摆弄”，导入后为 84 个运行时词。

## 运行时边界

- Excel 在用户通过脚本中心显式选择/拖入后仅在本地解析；运行时优先读取保存到当前浏览器扩展配置的词项，不存在时回退内置 `forbidden-terms.json`。
- 不保存 Excel 二进制、不上传词表、不自动读取用户磁盘；普通 `.xlsx` 以外、损坏、加密或无有效词的文件不会覆盖当前词表。
- 匹配规则是区分大小写的字面子串、最长词优先；不做词形归一、分词、模糊匹配或联网更新。

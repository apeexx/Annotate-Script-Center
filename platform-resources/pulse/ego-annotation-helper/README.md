# Pulse 分段标注助手资料

## 目录职责

- `page-structure/`：已采样标注页的 DOM 结构、时间换算输入和安全挂载点。
- `reference/`：本次用户提供的禁用词 Excel 参考源与 JSON 导入口径。

## 当前能力

- 从当前选中分段的内联 `left / width` 与时间线总宽度换算秒数；仅拖动分段框左右边界或其相邻拖拽柄时，额外按每次指针位移计算“分段长度 Ns · 变化 ±Ns”，因此不等待页面在松手后写回样式。分段框中间和普通进度条不参与预览。右上角已有的起止时间与秒数保持由 Pulse 原页面负责显示。
- 在精确“中文翻译” textarea 下方显示只读文本镜像；禁用词按大小写敏感的字面子串、最长词优先匹配，不改写标注文本。
- 原样显示用户确认的规则文案，保持原有换行，默认折叠。

## 禁用词词表

- 参考源：`reference/禁止使用词汇.xlsx`。
- 运行时主词表：`extension/sites/pulse/ego-annotation-helper/data/forbidden-terms.json`。
- 本次导入前共有 85 个词项；去除重复“摆弄”后为 84 个词。词表不含网络地址、Cookie、Authorization 或任务内容。

## 安全边界

- 不保存、不提交、不审核、不领取、不自动切换任务。
- 不调用 Pulse 平台接口；扩展内置词表读取失败时仅显示失败状态，不降级请求外部地址。
- 页面无法确认轨道、选中段、总帧数或帧率时仅显示待加载状态，不猜测时间。
